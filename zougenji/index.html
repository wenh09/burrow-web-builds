增愿寺 Web 版本索引

来自《消失的13级台阶》的山间破败寺庙，寺内供奉高大的不动明王木像。两个版本都是 Dream Agent 产出的垂直切片运行时，Godot 4.7.1 Web 导出，单线程 gl_compatibility。

操作：WASD 移动，鼠标转视角，Esc 释放光标。首次点击画面才会捕获鼠标。两个 pck 都不到 0.5 MB，加载很快。

垂直切片

  • 01 · 垂直切片 r003（绳索 / 窗户路线）
    world revision 3，契约 zougenji-slice-contract-v3，10 碰撞体。进入路线：缓坡壁架 → 绳索 → 窗口进入 → 一层大厅观景点。pck 0.41 MB
  • 02 · 垂直切片 r004（十三阶木梯）
    world revision 4，契约 zoaganji-vertical-slice-v4，8 碰撞体。十三阶木梯直接通向二层，梯上端设落脚平台。pck 0.45 MB

木梯固定为 13 阶（书中设定），单阶踢面约 0.18 m、踏面约 0.28 m，合计上升约 2.34 m、水平行程约 3.64 m，中心线坡度约 32.7°。二层楼板围绕楼梯口拆成多块以避免阻挡。
