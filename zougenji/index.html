《消失的13级台阶》里的山间破败寺庙，寺内供奉高大的不动明王木像。 两个 Dream Agent 垂直切片运行时，Godot 4.7.1 Web 导出，单线程 gl_compatibility。

WASD移动 鼠标转视角 Esc释放光标 两个 pck 都不到 0.5 MB，加载很快

垂直切片两条不同的上行路线

同一座寺庙的两次空间方案，区别在于怎么从室外到达上层。

  • 01r003 · 绳索 / 窗户路线

    缓坡壁架 → 绳索 → 窗口进入 → 一层大厅观景点。没有楼梯。

    world rev 310 碰撞体pck 0.41 MB
  • 02r004 · 十三阶木梯

    木梯直接通向二层，梯上端设落脚平台，二层楼板围绕梯口拆块以免阻挡。

    可上二层world rev 48 碰撞体pck 0.45 MB
