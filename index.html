陋居 Web 版本索引

Godot 4.7.1 Web 导出，单线程 gl_compatibility。必须经 HTTP 打开，直接双击 index.html 会因 file:// 被浏览器拦住。

操作：WASD 移动，鼠标观察，Space 跳跃，靠近前门按 E 开门，Esc 释放鼠标。首次点击画面才会捕获鼠标。
