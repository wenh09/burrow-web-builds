3D World · 生产路线对比

同一个小说场景，不同的做法能做到什么程度

三个来自小说的场景，每个都用不止一条路线做过一遍。放在一起是为了看清差别： 世界数据代理渲染、纸片美术、Blender authored mesh、Agent 管线， 以及单 Agent 零干预直接产出。全部为 Godot 4.7.1 Web 导出， 单线程 gl_compatibility，浏览器里直接进。

管线产出：world.json、Agent 编排或人工 authored 资产 Astra：单 Agent 直接产出，0 干预 0 约束

陋居

《哈利·波特》· 德文郡歪斜多层红顶房屋

四条路线，按投入从低到高排列。前三条是 world-agent 管线的不同阶段，最后一条是 Astra 独立重做。

  • 管线
    路线 1 · 世界数据 version 6 实体版本

    直接读 world.json 渲染，77 个实体只有原始盒体和颜色。看得出体量关系，没有任何 authored 几何。

    77 实体proxy render
  • 管线
    路线 2 · 卡片美术 纸片剧场 v1

    10 张分层卡片加 1 个可进入房间。用二维美术绕过建模，画面完成度高但只有一个视角成立。

    10 cardspck 16.4 MB
  • 管线
    路线 3 · authored mesh 完整室内 · clean_retro_3d

    1,057 mesh 的 Blender GLB，12 个房间、119 碰撞体，其中 8 个房间在楼上，有连续楼梯可以真的走上去。

    12 rooms可上楼pck 58.6 MB
  • Astra
    路线 4 · 单 Agent Astra · Hearth

    五层主屋、悬挑小书房、八个上层房间、连续折返楼梯，院落含鸡舍、菜园、果园、池塘。约 54.6 万三角面，65 组碰撞网格直接用可见网格的三角面。

    546k tris65 碰撞组全景 + 第一人称

增愿寺

《消失的13级台阶》· 山间破败寺庙，内供不动明王

两条路线做同一座寺庙，都要解决"十三阶台阶"这个书里的硬设定。

  • 管线
    路线 1 · Agent 管线 垂直切片 r004

    Dream Agent 产出的垂直切片。十三阶木梯通向二层，梯上端设落脚平台，二层楼板围绕梯口拆块以免阻挡。8 个碰撞体。

    world rev 4pck 0.45 MB
  • Astra
    路线 2 · 单 Agent Astra · 地层之下

    整寺被连续滑坡的泥土包覆。外围林地、滑坡面、调查平台栈道、绳索下降井、侧墙窗洞、两层木构大殿、不动明王雕塑。Tab 可切全寺剖视。

    剖视模式绳索升降pck 20.9 MB

汤屋

《千与千寻》· 神隐街道与汤屋

只有 Astra 一条路线，管线没做过这个场景。

  • Astra
    唯一路线 · 单 Agent Astra · 入夜之前

    食铺的灯刚亮起来的那个时刻。沿神隐街道走过红桥到汤屋门前，两侧摊铺、灯笼与招牌都可走近看。

    夜景街道 + 汤屋
WASD移动  鼠标环视  Space跳跃  Shift快步  Esc释放鼠标  — 各版本另有自己的键位，进去后看画面上的提示。首次点击画面才会捕获鼠标。

Astra 版本是单 Agent 在 0 干预 0 约束下直接产出的独立工程，没有复用管线的资产或代码。 管线版本来自 world-agent 的世界数据与 Agent 编排链路。

缩略图全部取自各版本在浏览器里的实际渲染画面，不是概念图或宣传图。 增愿寺 Astra 原工程用 forward_plus，Web 只支持 gl_compatibility， 发布副本切换了渲染后端并补入中文字体子集，原工程未改动。

源码与构建脚本在 wenh09/burrow-web-builds。
